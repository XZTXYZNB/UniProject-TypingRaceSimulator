# TypingRaceSimulator
## Overview：

This project simulates a typing race where multiple typists compete to complete a passage of text.

## The project is divided into two parts:

Part 1 (Text Version)

Part 2 (GUI Version)

## Requirements：

Java JDK 8 or higher

Terminal / Command Prompt

## Instructions to compile:

### Part 1
1. Open terminal
2. Navigate to Part1 folder: cd Part1
3. Compile: javac *.java
4. Run: java Race
### Part 2
1. Open terminal
2. Navigate to Part2 folder: cd Part2
3. Compile: javac *.java
4. Run: java TypingRaceGUI
